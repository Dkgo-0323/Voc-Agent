# VOC Agent 开发计划

更新：2026-10-22。这里是当前状态、阶段目标、验收标准和下一步的唯一动态计划入口；交付与周报写入 [开发记录](journal.md)，运行/演示见 [根 README](../../README.md)。

## 已确认的工作方式

用户在本聊天明确授权更新：每天北京时间12:00独立运行；周一集中调研、总结周报并据此制定/调整周方案，其余每天延续已确认阶段目标。由助手检查代码、制定方案、自主实现/验证/提交/普通推送，用户每天用约10–15分钟理解主线，不需要分批提交prompt。

每日目标为有实质价值、可验收的功能或工程成果，可覆盖多个模块和合理提交；不设提交数量指标，不把成果切成过小修改。跨天任务连续推进，记录当日已验收部分与剩余项。研究新证据不足以改变方向时继续原阶段。

只有新阶段目标、重要架构/产品/数据取舍、明显范围变化、调用预算/付费/凭据配置/正式发布等才需要 interview：先解释场景与概念，一次2–4题，每题2–3个选项，给推荐、理由、代价与交付影响。相关选择明确后再实施；方向不变的常规事项不重复确认。有阻碍时继续不依赖该决策的已授权工作。

## 项目主线与当前阶段
